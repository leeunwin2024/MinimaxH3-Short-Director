# MinimaxH3 Short Director

ComfyUI custom node project: Unwin MiniMax Director v1.1.4.

Install the `Unwin-MiniMax-Director` folder into your ComfyUI `custom_nodes` directory and restart ComfyUI.

Model weights, rendered videos, local project data, and Real-ESRGAN binaries are not included. See the extension README for setup and usage.
